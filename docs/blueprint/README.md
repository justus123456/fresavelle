## Interpretation

- Latest explicit user instructions override conflicting older text. The 15-minute inventory reservation at payment start is explicitly approved; it is not a payment deadline.
- **Approved** means explicitly directed by the user or labelled confirmed direction in the available handoff, not implemented. **Carried forward** means present in the earlier handoff but its original approval cannot be verified. **Proposed** means a design suggestion, not a decision. **Open** means unresolved. Never promote carried-forward or proposed details to approved silently.
- The full earlier conversation was unavailable to the source author and has not been recovered here. Both source files are retained, not overwritten. Clarify conflicts before their dependent functionality is implemented.
- Launch-scope lists are working planning categories, not proof every detail or release boundary has been approved. Proposed API routes, schema and permission matrices remain design material until validated.
